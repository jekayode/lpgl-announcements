# LifePointe Greater Lekki — Announcements

A lightweight, mobile-first announcements page for LifePointe Greater Lekki.
Built as a single static `index.html` (no build step, no backend) with optimized WebP images.

## View it live

GitHub Pages: https://jekayode.github.io/lpgl-announcements/

## Structure

- `index.html` — the page (tap any item to expand its details)
- `images/` — optimized WebP banners
- `assets/` — logos

To update: edit content in `index.html`, drop new source images in a working copy, re-optimize to WebP, and push.
